# MechWarrior: Destiny для Foundry VTT

Неофициальная игровая система для Foundry VTT по книге **MechWarrior: Destiny** (Catalyst Game Labs, Cue System). Для личного использования.

Совместимость: Foundry V13 (проверяется на 13.351), с заделом на V14.

## Установка

В Foundry: **Game Systems → Install System**, в поле *Manifest URL* вставить:

```
https://github.com/alexdunecat/Mechwarrior/releases/latest/download/system.json
```

Дальше Foundry сам предлагает обновления. Новый релиз собирается автоматически при каждом слиянии в `main`, если в `system.json` поднята версия.

### Проверка ветки до слияния

Каждый push в рабочую ветку собирает тестовый релиз `dev`. Его можно поставить по отдельной ссылке:

```
https://github.com/alexdunecat/Mechwarrior/releases/download/dev/system.json
```

Тестовая и основная установки используют одну папку `mechwarrior-destiny`, поэтому одновременно стоит только одна из них. После слияния достаточно переустановить систему по основной ссылке.

## Что уже работает

- Персонаж: атрибуты, навыки (из списка книги, с Gunnery/Piloting по типу техники и Knowledge с темой), черты, оружие, броня, инвентарь, Life Modules, Cues, Tags, биография.
- Condition Monitor: треки Physical и Fatigue, пипсы вычёркиваются по STR/WIL, штрафы рядов (–1…–4, складываются между треками), Staggered, KIA/KO, тест KIA (EDG+EDG, сложность растёт).
- Тесты: 2D6 + навык + атрибут против 2D6/3D6/4D6 ГМа; ничья в пользу игрока, натуральная 2 — провал, без навыка на Hard — провал; тесты атрибут+атрибут; ситуативный модификатор, помощники, черты, ранения учитываются автоматически.
- Edge: кнопки на карточке броска — перебросить свои кубы или заставить противника перебросить; одно очко на бросок, не больше EDG за сессию.
- Plot Points (0–5) и Edge на листе, броня с пипсами и снижением урона B/E, штраф брони к RFL.
- NPC: компактный лист как в книге.
- Личный бой: атака оружием с листа по выделенным целям (T), защита цели 2D6 + RFL + RFL + ранения считается сама; дистанция Close/Near/Far; обе стороны могут тратить Edge на карточке; кнопка «Применить урон» проводит урон через тип брони, пипсы брони и Condition Monitor, на карточке урона есть кнопка теста KIA.
- Проверка сознания (CON): кнопка на треке Physical, чистые 2D6 против CON нижнего заполненного ряда; при провале персонаж получает статус «без сознания»; кнопка Fight through it (Plot Point, +WIL). Автоматически бросается, когда пилот получает урон в бою мехов.
- Мехи: отдельный тип актёра с листом по книге — тоннаж и класс, Movement, прыжковые двигатели, Heat Dissipation, диаграмма брони (Armor/Structure по шести локациям, пипсы кликабельны), трек нагрева с уровнями, криты гироскопа, двигателя и ног, статусы (лежит, прыгал, выключен, Disengaged, уничтожен).
- Пилот и техника не связаны намертво: пилот выбирается на листе меха (список или перетаскивание персонажа), на вкладке «Техника» у персонажа хранится его парк машин, пересесть можно в один клик. Один НПС может сидеть сразу в нескольких машинах (раны у него при этом общие).
- Оружие меха и оборудование — отдельные предметы: Primary Weapon или Weapon Group, урон вида «4+M (Max 6)», Heat, дистанции Pointblank/Short/Medium/Long, локации установки; боезапас, прыжковые двигатели.
- Стрельба мехом: Gunnery пилота против Piloting пилота цели, модификаторы дистанции, нагрева, местности, скорости (моя Max Movement минус её), прыжка, беспомощной цели; по Disengaged цели нужна натуральная 11+. Нагрев от выстрела добавляется сразу.
- Физические атаки: удар рукой, пинок, толчок, таран и death from above с уроном от тоннажа и уроном себе.
- Урон по меху: бросок локации (отдельные таблицы для ударов и пинков), кубы ракет с потолком Max, броня → структура → перенос в торс, проверка крита 8+ и таблица критов, уничтожение оружия и оборудования в локации, взрыв боезапаса, касательное попадание в голову (полный урон за Plot Point), урон пилоту 3 с проверкой CON, падения и тест Piloting.
- Конец Narration: охлаждение (с поправкой на повреждённый двигатель), броски на отключение и взрыв боезапаса, перезапуск двигателя.
- Боевая техника (танки, ховеры, колёсные машины, VTOL): свой лист с диаграммой брони (перед, борта, корма, башня или винт), урон без переноса между частями, проверка ходовой (8+ → –2 Movement), криты техники (экипаж, оглушение, оружие, ходовая, боезапас), таран, авария с уроном экипажу. Тепло технике не нужно.
- Аэрокосмические истребители: броня по частям (нос, крылья, хвост) и общая структура, проверка крита при 2+ урона по части, таблица критов 2D6 (авионика, топливный бак, двигатель, бомбы, кабина), нагрев, потеря управления и её восстановление.
- Экипаж: у техники и истребителя есть пилот и другие члены экипажа, они получают урон от попаданий в кабину и аварий. Gunnery и Piloting берутся по специализации (мехи, техника, авиация).
- Смешанный масштаб: оружие меха по человеку (–2, повторный бросок на прямое или непрямое попадание, Plot Points, чтобы смягчить или избежать попадания, непрямой урон ×10 через броню), человек по меху (+2 вблизи, урон копится и каждые 20 дают 1 урон по машине).
- Создание персонажа: мастер по 13 шагам книги (кнопка «Создание» на листе) — образ, фракция, уровень опыта, атрибуты и навыки с подсчётом очков, черты из книги или свои, Life Modules с +1 к навыку и требованиями, стартовая броня, оружие (из списка, перетаскиванием или своё), инвентарь, стартовая машина по Hardware Points с проверкой навыков, превращение остатка в XP, очки навыков или EDG, варианты Dispossessed и Hardware Pool, Cues и предыстория. Нарушения правил показываются предупреждениями, ГМ может их разрешить.
- Развитие (вкладка «Развитие»): повышение атрибутов и навыков за XP по таблице книги, новый навык, покупка положительной черты и снятие отрицательной, модификация оружия (Accuracy, Lethality, Range), ремонт и восстановление техники, покупка, трофей или сохранённые Hardware Points. Все траты пишутся в журнал, последнюю можно отменить. ГМ выдаёт XP кнопкой.
- Hardware Points машины считаются сами по типу и классу.
- Черты с эффектами: Toughness (–1 к урону в Condition Monitor), Glass Jaw (+1), Pain Resistance (без штрафа –1), Unlucky (шестёрки на своём переброске Edge считаются единицами), модификатор инициативы.
- Панель Plot Points (Shift+P или звезда в инструментах токенов): очки всех игроков, трата с выбором применения, пул ГМа (потраченные игроками очки уходят ГМу), кнопка «Новая сессия» (3 очка и полный Edge всем, пул ГМа 1).
- Порядок ходов в трекере боя (настройка системы): по книге (сторона ГМа, затем игроки по порядку), бросок инициативы 2D6 + бонус (ничьи по EDG и RFL) или вручную.
- Интерфейс на русском и английском.

## Разработка

```bash
npm install
npm test
```

Логика правил лежит в `module/rules/` и не зависит от Foundry, поэтому проверяется тестами на Node. Для работы с живой системой удобно сделать символическую ссылку из `Data/systems/mechwarrior-destiny` на папку репозитория.

Структура:

- `module/config.mjs` — данные правил (атрибуты, навыки, сложности, уровни опыта).
- `module/rules/` — чистые функции: тесты, Edge, Condition Monitor, урон, порядок ходов, бой мехов.
- `module/data/` — модели данных актёров и предметов.
- `module/documents/`, `module/sheets/`, `module/dice/`, `module/apps/` — интеграция с Foundry.
- `templates/`, `styles/`, `lang/` — интерфейс.
